# 演示病例

## P008 · 孙某某 —— 骨科（关节亚专科）

68 岁女性，双膝骨关节炎 5 年，右膝 K-L Ⅳ级伴夜间静息痛，保守治疗失效，
具备全膝关节置换指征。**这个病例是为「术前风险叠加」造的**，不是为了多一个科室。

### 它要演示的那条线

**头孢过敏 × 在用头孢呋辛酯片 → 高风险硬规则红线。**

社区医院因牙痛开了头孢呋辛，患者自己忘了几十年前的过敏史 ——
跨机构处方没人做过敏史核对。这是关节置换术前最真实的坑：
一线预防性抗生素正是头孢菌素类，不发现就要出事。

对话脚本里医生问到「我看您在吃头孢呋辛，是哪儿开的？」，患者答
「上礼拜牙疼，社区医院给开的」，然后才想起过敏史 —— 这一段是刻意写的，
它让红线的来龙去脉在问诊里就说清楚，不用靠界面解释。

> **改 fixture 时注意**：过敏原必须写「头孢」而不是「头孢菌素类」。
> 硬规则是子串匹配（`term in drug`），「头孢菌素类」不是任何真实药名的子串，
> 改了规则就静默失效，而界面看起来一切正常。
> `test_p008_allergy_conflict_fires` 钉着这一条。
