## 2. Mock 运行效果

医生界面默认生成正常演示结果，不显示运行场景选择器。以下六种效果均保留在统一任务契约中，其中异常场景通过自动化测试或本地测试请求注入：

1. 正常结果：返回可复核的结构化临床 Mock 内容。
2. 需要澄清：阻断普通结果，展示必答/建议问题，补充后可重新运行。
3. 数据冲突：显式显示冲突，不静默合并来源不一致的信息。
4. 降级结果：保留可用内容，同时显示“降级结果”标识和不确定性。
5. 运行失败：不展示未经校验的临床内容，提供重新运行路径。
6. Schema 拒绝：将不符合契约的结果安全拒绝，不把原始内容暴露到产品界面。

## 4. 本机浏览器验收

验收地址：`http://127.0.0.1:4173/#/outpatient`。

已实际验证九个医生入口均可用：智慧诊疗、风险预警、病历管理、诊断管理、医嘱管理、共病管理、健康档案、时间轴和语音问诊。智慧诊疗自动并行生成病情概要与鉴别诊断，必须排除项左下角可显示“风险预警”，点击“查看详细”进入风险预警；风险列表的详细内容默认收起，可逐项展开或收起，展示证据、来源、阈值、不确定性、评估引用和技能引用。智能笔记在语音问诊完成前保持等待；医患对话逐条出现在最右侧医生智能体，动态追问提示紧贴其左侧浮动。问诊结束后，中间智能笔记自动生成主诉、现病史、既往史、个人史、过敏史、体格检查、辅助检查和初步诊断八类字段。重新生成保持患者和功能上下文一致；医嘱管理可加入医嘱草稿并生成回写确认单；医生界面不再显示“Mock 效果”或“Mock 环境”。异常状态继续由自动化覆盖。
