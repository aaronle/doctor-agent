# Doctor Agent UI/UX 决策记录：沿用最早 HTML

版本：`v0.3-confirmed`  
确认日期：`2026-08-28`  
原文件名为“Demo 审视与北大医疗 UI/UX 优化方案”，为保持历史链接有效而不改名。

## 1. 当前有效决策

产品负责人已确认：一期界面使用最早的 [`AI-HIS门诊模块V4.3.html`](../../references/ui-demo/AI-HIS门诊模块V4.3.html)，UI/UX 不做重新设计。

因此，此前关于新版统一医生智能体工作区、三栏宽度、新设计令牌、新卡片体系、新证据抽屉、新风险顶栏以及用 Figma/新版原型替代最早 HTML 的建议，全部退出一期基线，仅作为历史探索。

## 2. 一期实施口径

- 原 HTML 是不可修改的历史原件；`design/current/AI-HIS医生智能体一期.html` 是当前产品直接实现基线。
- 7 个功能在原界面现有模块中增量接入。
- Agent 调用状态、结果和人工确认尽量复用原组件表达。
- 前端可以迁移技术实现，但不得因此改变用户可见界面和交互。
- 如功能无法被现有区域承载，先提交差异清单等待确认。

## 3. 品牌例外

当前已确认删除“惠每”两字，但暂不自动补入新的品牌前缀；正式机构名称与 Logo 等待院方后续确认。登录按钮改为“进入医生智能体”，登录成功直接进入 `/outpatient`，跳过患者选择。

## 4. 历史设计稿处置

- Figma 文件和 `design/prototype/` 下的新版原型保留用于追溯，不作为实现依据。
- 后续不得从历史探索稿反向生成生产代码。
- 测试截图和 UI 对照应使用最早 HTML，而不是历史探索稿。

详细实施与验收规则见 [`02-UIUX详细规格与页面Mockup.md`](02-UIUX详细规格与页面Mockup.md)。
