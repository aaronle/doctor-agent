# 患者预问诊（移动端）

日期：`2026-09-08`
设计稿：Figma **「12 · 移动端重构（患者预问诊 + 医生端）」**，七屏 390×844。

---

## 一、移动端现在有两条路

打开先问「你是谁」。两边看到的东西**完全不同**：

| | 患者 | 医生 |
| --- | --- | --- |
| 登录 | 病人号 + 姓名 | 工号 |
| 能看到 | 只有自己填的内容 | 全部临床数据 |
| 路由 | `/previsit` | `/outpatient/*` |

**接口层面就分开，不靠界面藏。** `/api/previsit/login` 的返回体里没有诊断、
没有检验、没有风险等级 —— 「界面不显示」不算数，接口不给才算。

## 二、预问诊问的是什么

通用 4 题（所有科室）+ 专科 4 题。妇科、内分泌、心内、骨科、神内各配了一套，
题库在 `references/ui-demo/extracted/fixtures/previsit-questions.json`。

四条出题原则：

**① 不用术语。**「末次月经」患者不一定懂，改成「上一次月经是哪天开始的？」，
医生端再翻回「末次月经」。让医生读患者的措辞、和让患者读术语，
是同一个错误的两个方向。

**②「记不清」永远是合法答案。** 逼患者在不知道时选一个，产出的是
**看起来像数据的猜测** —— 而它会一路进到病历里，比空着更糟。

**③ 敏感题说明为什么问。** 生育史那题写「影响用药和检查怎么选」。
不解释，患者要么跳过要么乱填。

**④ 只采事实，不下判断。** 不问「你觉得是不是心绞痛」。

## 三、一条安全约束：患者自报的过敏史不改档案

患者在手机上点「没有过敏」，与医生问过并确认，是两件事。

如果让它自动改 `allergy_status`，那条**提醒医生补问的中风险告警会当场消失** ——
而下游的过敏冲突红线正建立在它之上。等于用患者候诊时的一次点击，
换掉了整条用药安全链的起点。

所以：
- 档案状态**不动**，告警**不消**
- 医生端显示「患者自填：青霉素 · **待确认**」，并写明「你问过并确认后，
  档案才从未采集变成已确认」
- 患者端也说清「医生还会再问一次」—— 不说，他会以为填了就算数，
  医生再问时反而觉得系统没记住

三处文案互相咬合，缺一处这条约束就会被误读成 bug。

## 四、落到病历

`build_context` 里单独一层 `previsit`，**带 `source`，不与医生问出来的合并**。
病历提示词据此要求标「患者自述」，并额外钉一句：过敏项**不得当作已确认
写进既往史**。

真机实测（P009，21.1s）：现病史里出现「患者自述前一个月于外院开具止血药和铁剂」，
来源标出来了。

## 五、字号：默认档就是原来的「特大」

产品反馈「移动端的字体太小了」。做法是把整条标尺**右移一档**，不是加一档更大的：

| | 改前 | 改后 |
| --- | --- | --- |
| 小 | 0.9 | 1.15 |
| **默认** | **1.0** | **1.3** |
| 大 | 1.15 | 1.45 |
| 特大 | 1.3 | 1.6 |

原来的默认 1.0 落到了「小」这一档之下，直接砍掉 —— 没人需要比原来更小。

**只动移动端。** 桌面端的字号压在还原度门禁下（119 个元素逐条比计算样式），
那道门禁守的是「与 V4.3 原件一致」，不该为了手机上的可读性去破坏它。

顶栏与标签栏**直接写大**，不靠 `zoom`：`zoom` 挂在 `.m-body`，够不着它们
（`.m-page` 是 `position:fixed`，给它加 `zoom` 会让浮层算错大小）。
不改的话会出现「正文很大、导航很小」的割裂，而导航恰恰是要点的地方。

患者端另起一套 `PreVisit.scoped.css`，不复用 `mobile.css` ——
后者是医生端的信息密度（一屏塞八块），患者端要的恰恰相反：一次一题、留白足够。

## 六、这一轮里我自己踩的坑

**四条用例是空过的**，全被变异验证抓出来：

| 用例 | 为什么空过 |
| --- | --- |
| 「登录不说哪项错了」 | 按关键词断言，把「病人号与姓名对不上」这句**正确**的文案判成泄露。真正的判据是两次回复完全一致 |
| 「每题都给出口」 | 没考虑能自由填字的题 —— 输入框本身就是出口 |
| 「未作答的题不显示」 | 数据里根本没有空答案，过滤器无事可做，删掉 `.filter()` 照样绿 |
| 「患者自报不改档案」 | 变异脚本设了 `patient.allergy_status`，而它其实存在 `payload` 里 —— 改了个不存在的属性 |

还有一次路径写错：`previsit.py` 在 `routers/` 下，比 `seed.py` 多一层，
照抄它的 `parents[3]` 指到了 `apps/`。
